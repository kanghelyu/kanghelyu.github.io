Stacks Project · Dark Mode

在深色背景下阅读代数几何圣经

📌 Bookmarklet（推荐）

把下面的按钮拖到浏览器书签栏。之后每次打开 Stacks Project 的页面，点一下这个书签就能切换深色模式。

🌙 Stacks Dark

  1. 按住上面的 「🌙 Stacks Dark」 按钮
  2. 拖到浏览器的书签栏
  3. 打开任意一个 Stacks Project 页面
  4. 点击书签栏里的 🌙 Stacks Dark

⚡ Ctrl+Shift+D 快捷键

在任何 Stacks Project 页面上按 Ctrl+Shift+D（Mac: Cmd+Shift+D）一键切换深色模式。
注意：你需要先用书签或控制台的方式注入一次脚本，快捷键才会生效。

🖥 控制台注入（临时测试）

打开 Stacks Project 页面的开发者工具（F12 → Console），粘贴以下代码然后回车：

var s=document.createElement('script'); s.src='https://cdn.jsdelivr.net/gh/kanghelyu/kanghelyu.github.io@main/stacks-dark/dark-mode.js'; document.body.appendChild(s); var l=document.createElement('link'); l.rel='stylesheet'; l.href='https://cdn.jsdelivr.net/gh/kanghelyu/kanghelyu.github.io@main/stacks-dark/dark-mode.css'; document.head.appendChild(l);
