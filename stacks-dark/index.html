Stacks Project · Dark Mode

在深色背景下阅读代数几何圣经

📌 Bookmarklet（推荐）

把下面的按钮拖到浏览器书签栏。之后每次打开 Stacks Project 的页面，点一下这个书签就能切换深色模式。

🌙 Stacks Dark

  1. 按住上面的 「🌙 Stacks Dark」 按钮
  2. 拖到浏览器的书签栏
  3. 打开任意一个 Stacks Project 页面
  4. 点击书签栏里的 🌙 Stacks Dark

⚡ 直接用（临时）

在当前 Stacks Project 页面按下 Ctrl+Shift+D（Mac: Cmd+Shift+D），或者把下面这段代码粘贴到浏览器控制台（F12 → Console 标签页）：

var s=document.createElement('script');
s.src='https://kanghelyu.github.io/stacks-dark/dark-mode.js';
document.body.appendChild(s);
var l=document.createElement('link');
l.rel='stylesheet';
l.href='https://kanghelyu.github.io/stacks-dark/dark-mode.css';
document.head.appendChild(l);
